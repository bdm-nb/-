# 眼在手视觉伺服闭环练习报告

**项目名称：** 眼在手上的标签视觉伺服：静态对准 + 运动跟踪与延迟控制对照  
**适用对象：** 已进组、尚未承担课题的本科生（控制专业）  
**定位：** 大二科研预备练习，不是投稿稿件  
**后续衔接：** 大三在真机环上只加一个控制增量（延迟稳定或 6/7 轴对照），再投 RA-L / ICRA / IROS 或国内会议  

---

## 1. 项目一句话

MoveIt 1 只负责粗接近；每一帧用 ArUco 的像素误差生成运动量，不经规划器走长轨迹。本机为 ROS 1 Noetic + `abb_driver`：有速度接口则写速度，否则用短笛卡尔增量。先完成静止标签对准，再增加慢速运动目标和人为图像延迟，比较三种控制律。视觉只提供误差，思考与评价都偏控制：稳、准、快。命令对照见 [NOETIC_ADJUST.md](../NOETIC_ADJUST.md)。

---

## 2. 目标与非目标

### 2.1 要达到的目标

- 能独立启动仿真，完成“接近 → 视觉闭环 → 停止”状态机。
- 理解 Commander / MoveIt / `ros2_control` 各自停在哪一层。
- 能解释开环“看一次再规划”和闭环“每帧改速度”的差别。
- 能用表格说明增益、延迟、目标运动对振荡和跟踪误差的影响。
- 代码整理后可在 GitHub 开源（去掉实验室内部驱动与未授权模型）。

### 2.2 明确不做

- 检测网络、SLAM、导航、VLA。
- 自研机械臂、新夹爪、改厂家 driver。
- 把练习包装成 SCI / 顶刊题目。
- 第 3 关未稳定时并行上力觉、双臂、两台真机对照。

## 3. 详细分块

练习按关卡推进。上一关的“过关标准”不满足，不进入下一关。

### 第 0 关：工作空间能跑

**内容**

- 使用已有 `workspace_ws` / `robot_gripper` 描述、MoveIt、bringup。
- `colcon build` 通过，launch 后 Gazebo 或 RViz 中臂与夹爪可见。

**交付**

- 一条可复现的启动命令（写进笔记）。
- 一张 RViz/Gazebo 截图。

**过关**

- 不改业务代码也能反复启动，关节状态话题有数据。

---

### 第 1 关：Commander 流程（开环作业）

**内容**

- 写死预抓取位姿与下降位姿。
- Commander 调用 MoveIt：到预抓取点 → 笛卡尔直线下降 → 夹爪开合。
- 用 `joint_states` 确认臂确实在动。

**对应层次**

```
状态机 → Commander → MoveIt 规划 → joint_trajectory_controller → hardware / 仿真插件
```

**交付**

- 一个 Commander 节点或脚本。
- 连续成功两遍的录屏或 bag。

**过关**

- 不依赖视觉，流程可重复。此时还没有科研闭环。

---

### 第 2 关：看见，但仍开环

**内容**

- 末端或固定架增加仿真相机，场景中放置 ArUco。
- 检测标签，得到像素中心或相机系位姿。
- 经手眼变换（仿真可先写死准确外参）得到基座系目标。
- 目标仍交给 Commander / MoveIt，只看一次再规划。

**交付**

- 检测节点：发布标签位姿或像素坐标。
- 挪动一次标签后，臂能走到新位置。

**过关**

- 能说清：这是开环视觉引导，不是闭环控制。

---

### 第 3 关：静态视觉速度闭环（核心）

**内容**

- 粗接近仍用第 1 关（MoveIt）。
- 进入伺服后停止规划。
- 每帧计算像素误差 \(e\)（标签中心相对图像中心，或特征点堆叠误差）。
- 控制律第一版：\(v = -\lambda e\)（相机系速度），再经雅可比变为关节速度。
- 命令写入 `ros2_control` 速度接口（或等效笛卡尔速度接口）。
- 看丢目标、超速、超出工作空间必须停。

**对应层次**

```
图像 → e → 伺服律 → 笛卡尔速度 → J⁺ → 关节速度 → ros2_control
         ↑________________ 闭环 ________________↑
```

**交付**

- 伺服节点（与 Commander 分离）。
- 状态机：`APPROACH` / `SERVO` / `HOLD` / `ABORT`。
- 一段可重复的对准视频：标签初始偏置，十字回到中心。

**过关**

- 不重新调用 `plan()` 也能把误差压下去。
- 能指出一次失败原因（符号反、坐标系错、\(\lambda\) 过大振荡）。

---

### 第 4 关：静态对照实验（稳、准、快）

**内容**

- 同一初始偏置、同一场景。
- 对比：第 2 关开环 vs 第 3 关闭环。
- 每组重复多次，记录失败。

**指标**

| 指标 | 含义 | 对应课题组用语 |
|---|---|---|
| 稳态像素误差 | 停下来后 \(|e|\) | 准 |
| 调节时间 | 进入阈值并保持的时间 | 快 |
| 超调 / 振荡次数 | 是否来回晃 | 稳 |
| 成功率 | 超时或看丢算失败 | 综合 |

**交付**

- 一张表 + 误差曲线（从 bag 画）。
- 简短文字：为什么闭环更准或在何种情况下更晃。

**过关**

- 数字来自重复实验，不是一次成功演示。

---

### 第 5 关：运动目标 + 图像延迟 + 三种控制律（含金量）

**前置：** 第 3 关静态闭环稳定。

**内容**

- 标签沿滑轨或转台慢速移动（仿真）；真机可用手缓慢挪标签纸。
- 软件加入可调图像延迟（例如 50 ms、100 ms、150 ms）。
- 三种律，接口相同，只换控制块：

1. **固定比例：** \(v = -\lambda e\)  
2. **按延迟降增益：** \(\lambda\) 随估计延迟减小，优先保稳  
3. **一拍预测：** 用上一拍速度把误差向前推一小步，再算 \(v\)

**对照表（必须做满）**

| 条件 | 律 1 | 律 2 | 律 3 |
|---|---|---|---|
| 静止、无延迟 | 基线 | — | — |
| 静止、有延迟 | 往往振荡 | 应更稳 | 看是否更快 |
| 慢速运动、有延迟 | 滞后或振荡 | 稳但可能慢 | 跟踪误差与超调 |

**交付**

- 延迟可在 launch / 参数中复现。
- 三种律的误差曲线与表格。
- 失败分析：预测在何种延迟下比降增益更差。

**过关**

- 能用控制语言解释，而不是“我把 \(\lambda\) 调小了就好了”。
- 此关是大三论文的种子，仍不作为独立顶刊题目。

---

### 第 6 关（可选，进组真机）：同一套节点换硬件

**内容**

- 实验室臂官方驱动、真相机、打印标签、手眼标定。
- 先复现第 3、4 关，再视时间做第 5 关（手移标签 + 软件延迟）。
- 7 轴浅零空间与力觉切换 **不在本练习必做范围**，留给大三课题。

**占机**

- 熟悉设备：少量几次上机。
- 采集对照：集中两三回即可。调参回仿真，避免在臂上盲调。

**交付**

- 手眼误差记录、真机 bag、与仿真同一套指标表。

## 4. 知识体系

按“用在哪一关”组织，避免按课程名堆砌。

### 4.1 体系总图

```
任务状态机
    ├─ 自由空间接近     机器人学 + MoveIt + Commander
    ├─ 视觉测量         相机模型 + ArUco + 手眼
    ├─ 伺服控制律       误差、增益、延迟、预测（偏控制）
    └─ 关节执行         雅可比 + ros2_control + 驱动 / 仿真
```

### 4.2 分块知识表

| 知识块 | 具体内容 | 用在哪一关 | 深度要求 |
|---|---|---|---|
| ROS 2 工程 | 话题、launch、bag、参数、坐标系 TF | 全程 | 能独立排错 |
| 模型与仿真 | URDF、Gazebo 相机、物理插件 | 0～5 | 会改相机与标签位姿 |
| 规划与接口 | MoveIt 规划组、Commander、`JointTrajectory` | 1～2 | 知道何时必须退出 |
| 关节执行 | `ros2_control`、速度/轨迹接口、仿真 hardware | 1、3、5 | 会换控制器，不写 driver |
| 刚体变换 | \(T_{base}^{ee}\)、\(T_{ee}^{cam}\)、误差在哪个坐标系 | 2、3、6 | 必须手推一条链 |
| 速度运动学 | 几何雅可比、阻尼最小二乘（近奇异） | 3、5 | 会写成代码 |
| 视觉测量 | 针孔模型、内参、ArUco、像素误差 | 2～6 | 特征保持简单 |
| 闭环控制 | \(v=-\lambda e\)、限幅、停机条件 | 3、4 | 核心 |
| 延迟与离散 | 帧率 vs 控制周期、迟后误差、降增益、一拍预测 | 5 | 含金量 |
| 实验方法 | 重复次数、失败定义、曲线与表 | 4、5、6 | 进组展示靠这个 |

### 4.3 控制思想（本练习要建立的）

- **稳：** 延迟下不振荡、看丢能停。  
- **准：** 稳态像素误差、手眼误差是上限。  
- **快：** 调节时间；增益过大用“快”换“稳”不算成功。  
- **开环快而不准、闭环准而可能晃** —— 必须用表说话。

### 4.4 刻意不纳入本阶段的知识

最优控制 / MPC、李雅普诺夫正式证明、深度检测、力控导纳（大三可选接触增量再学）、EtherCAT 从零编写。

## 8. 风险与排错优先级

| 现象 | 先查 | 不要先做 |
|---|---|---|
| 臂不动 | launch、控制器是否 active | 改伺服公式 |
| 检测有位姿但走错 | TF、手眼乘序 | 换标签种类 |
| 对着干 / 反向 | 误差符号、相机轴 | 加大 \(\lambda\) |
| 对准时振荡 | \(\lambda\)、延迟、未限幅 | 加 YOLO |
| 一闭环就规划失败 | 是否仍在调 MoveIt | 继续堆路点 |
