## 摘要

本练习面向机械臂“视觉—控制闭环”方向，要求练习者在实验室已有 ROS 1 Noetic 臂包（`arm_description`、`arm_moveit_config`、`abb_driver`、`vi_grab`）上，独立完成一条可运行的眼在手伺服链路。系统分为两段：自由空间粗接近由 MoveIt 1 Commander 规划并经轨迹接口跟踪；进入伺服后停止规划长轨迹，每一帧由 ArUco 标签给出像素误差，经控制律生成运动量。有关节速度接口则写速度；ABB 常见只有轨迹接口，则走短笛卡尔增量。练习先完成静止标签对准与开环/闭环对照，再增加慢速运动目标与人为图像延迟，比较固定比例、按延迟降增益与一拍预测三种控制律。视觉特征保持简单，思考与考核均偏控制。本报告给出项目总述、知识体系、分关详细操作与进度考核，作为进组后的可执行训练文件。本练习本身不构成顶刊投稿题目；大三年级可在真机环上增加延迟稳定或冗余轴约束后，再考虑会议或 RA-L 投稿。

**关键词：** 视觉伺服；图像闭环；MoveIt 1；ros_control / ABB 轨迹；延迟；机械臂控制

## 第一章 项目总述：本练习在做什么

### 1.1 要解决的现象

课程与多数入门项目把机械臂作业写成：检测一次物体位姿，调用 Commander 让 MoveIt 规划一条关节轨迹，驱动器跟踪该轨迹至终点。这是开环视觉引导。相机在运动过程中不再进入控制律，标定误差、延迟与目标微动都会在终点表现为偏差，也无法用“稳、准、快”评价一条真正的闭环。

课题组方向是视觉—控制闭环：视觉担任感知，输出误差；控制担任调节，强调稳定、准确与快速。本练习把这一方向落实为可独立完成的仿真（及可选真机）任务，使练习者从“理解功能包分工”转入“亲手闭合控制环”。

### 1.2 项目在系统里做什么

一次完整练习运行包含下列阶段，不得跳步理解。

**（1）启动与使能。** 加载机械臂与夹爪的 URDF、MoveIt 规划组、`ros2_control` 控制器及仿真（或真机）硬件接口。此阶段不产生作业智能，只保证关节可被命令。

**（2）粗接近（开环规划）。** 状态机发出预抓取或预对准位姿。Commander 与 MoveIt 在自由空间规划无碰路径，`joint_trajectory_controller` 跟踪关节轨迹，将末端送到相机能够稳定看见标签的区域。此段允许使用规划器，因为尚未进入接触，也不要求像素级精度。

**（3）视觉测量。** 眼在手相机采集图像，检测 ArUco 标记，得到标签中心像素（及可选的相机系位姿）。误差定义为特征相对图像参考点（通常为图像中心或期望像素坐标）的偏差。手眼变换将相机系信息与法兰、基座系统一。本练习不引入深度学习检测器，以保证误差信号可重复、可解释。

**（4）闭环伺服（本项目的主体）。** 状态机切换至伺服后，不再调用 MoveIt 的 `plan()`。每一控制周期：读取最新图像误差 → 控制律计算相机系（或基座系）速度 → 雅可比伪逆得到关节速度 → 写入 `ros2_control` 速度接口。环的闭合发生在“误差—速度—关节运动—新图像”之间。看丢失、超速或超出工作空间时必须进入停机。

**（5）评价。** 以稳态像素误差衡量准，以调节时间衡量快，以振荡次数与延迟下是否发散衡量稳。先比较开环规划到位与闭环伺服，再在运动目标与人为延迟下比较三种控制律。

**（6）含金量延伸。** 在静态闭环稳定之后，使标签慢速运动，并在软件中缓冲图像以模拟 50 ms、100 ms、150 ms 延迟。比较：固定比例律、随延迟降低增益、利用上一拍速度对误差作一拍预测。此段训练离散闭环与迟后系统下的增益选择，为后续偏控制的科研题目留接口。

### 1.3 与功能包层次的对应

| 层次 | 在本项目中的职责 | 典型软件 |
|---|---|---|
| 任务状态机 | 切换接近、伺服、保持、中止 | 自编节点 |
| 规划与指令接口 | 仅粗接近 | MoveIt、Commander |
| 视觉测量 | 输出误差，不输出关节角 | OpenCV、ArUco |
| 控制律 | 由误差生成速度 | 自编伺服节点 |
| 关节执行 | 跟踪轨迹或跟踪速度 | `ros2_control` |
| 硬件或仿真 | 读编码器、写执行器 | 仿真插件或厂家驱动 |

练习者必须能口头说明：Commander 不是驱动；MoveIt 不承担像素闭环；关节算法与轨迹跟踪在 `ros2_control` 一侧。

### 1.4 训练定位、成果边界与开源

本文件是练习指导书。完成第 3 关静态闭环，达到进组演示的最低要求；完成第 5 关三种律对照，达到本练习的含金量要求。不得将“实现了 ArUco 视觉对准”表述为已完成顶刊工作。代码在去除实验室内部地址、未授权商业网格与付费课程源码后，可用 MIT 许可证公开；若使用组内未发表数据或内部驱动，须事先征得导师同意。

## 第二章 知识体系

知识按“本练习必须用到的块”组织，不按课程目录堆砌。

### 2.1 体系结构

任务状态机统摄四条支路：自由空间接近依赖机器人学、MoveIt 与 Commander；视觉测量依赖相机模型、ArUco 与手眼标定；伺服控制律依赖误差定义、增益、限幅、延迟与预测；关节执行依赖雅可比与 `ros2_control`。

### 2.2 分块要点与深度

**ROS 2 工程。** 话题、参数、launch、坐标系 TF、rosbag2。要求能独立判断节点是否启动、控制器是否处于 active。用于全部关卡。

**模型与仿真。** URDF/Xacro、Gazebo 相机插件、标签模型。要求会把相机挂到末端连杆，并确认图像话题有数据。用于第 0 至关卡 5。

**规划接口。** 规划组名称、`setPoseTarget` / `setJointValueTarget`、`plan` 与 `execute`、笛卡尔直线。要求明确伺服段必须退出规划。用于第 1、2 关。

**关节执行。** `joint_trajectory_controller` 与速度控制器的分工、仿真 hardware 与真机 hardware 的替换关系。要求会查看控制器列表，不编写厂商底层驱动。用于第 1、3、5、6 关。

**刚体变换。** \(T_{\mathrm{base}}^{\mathrm{ee}}\)、\(T_{\mathrm{ee}}^{\mathrm{cam}}\)、像素到相机轴的符号。要求能在纸上写出一条完整变换链。用于第 2、3、6 关。这是闭环方向错误时的第一排查点。

**速度运动学。** \(\dot{q}=J^{+}v\)，近奇异时的阻尼伪逆。要求写成与 URDF 关节顺序一致的代码。用于第 3、5 关。

**视觉测量。** 针孔投影、内参、ArUco 字典与边长、像素误差向量。要求特征简单、可重复，不升级检测器来掩盖控制问题。用于第 2 至关卡 6。

**闭环控制。** \(v=-\lambda e\)、速度限幅、进入阈值后的保持条件、看丢停机。这是第 3、4 关的核心。

**延迟与离散。** 图像帧率与控制周期不一致、使用过时误差等于对系统加油门、降增益保稳、一拍预测的超调风险。这是第 5 关的核心，也是大三课题的接口。

**实验方法。** 固定初始偏置、重复次数、失败定义（超时、看丢、超限）、由 bag 生成曲线。用于第 4、5、6 关。无表格的演示视为未完成评价。

### 2.3 本阶段不纳入的内容

深度学习检测、SLAM 与导航、最优控制与 MPC、完整李雅普诺夫证明、从零编写 EtherCAT 主站、新型末端机构。上述内容或超出练习周期，或把问题中心从控制挪走。

### 第 1 关 Commander 开环作业流程

**目的。** 用代码而不是 RViz 按钮完成“到预位姿—下降—开合”，把状态机搭起来。本关没有视觉，却是后续关卡的骨架。

**原理。** Commander 只发送目标；MoveIt 输出 `JointTrajectory`；`ros2_control` 跟踪。练习者应在代码注释中写明这三步，避免把 `go()` 理解成驱动器。

**操作步骤。**

1. 在 RViz 中手动规划一个安全的预对准位姿与一个略低的下降位姿，记下基座系坐标或关节角，作为写死目标。
2. 新建节点（C++ 的 `MoveGroupInterface` 或课程中的 Python 接口）：依次执行预对准、笛卡尔直线下降、夹爪开合、抬起。每步之间等待前一步 `SUCCESS`。
3. 状态机枚举建议：`IDLE`、`APPROACH`、`DESCEND`、`GRASP`、`LIFT`、`DONE`、`ERROR`。任一步失败进入 `ERROR` 并停止后续运动。
4. 用 `ros2 bag record /joint_states` 录制一次全过程，确认各阶段关节有变化。
5. 连续自动运行两遍，中间不手动拖目标。

**检查。** 终端打印每步状态；RViz 中轨迹与实物（仿真）一致；夹爪关节有开合。

**常见问题。** 笛卡尔直线规划失败：减小下降距离或提高 `eef_step` 的合理性，检查起始态是否接近奇异。执行成功但看不见运动：控制器未 active。

**过关标准。** 一键脚本连续成功两遍。未达此标准不得加入相机。

### 第 2 关 开环视觉引导

**目的。** 让图像进入系统，但目标仍只计算一次并交给规划器，从而与第 3 关形成对照。

**原理。** 检测给出 \(T_{\mathrm{cam}}^{\mathrm{tag}}\) 或像素位置；手眼给出 \(T_{\mathrm{ee}}^{\mathrm{cam}}\)；与当前 \(T_{\mathrm{base}}^{\mathrm{ee}}\) 连乘得到基座系预对准位姿。该位姿只在伺服前使用一次，运动过程中不再更新，故为开环。

**操作步骤。**

1. 在 URDF 中将相机 link 固定于末端，使用 Gazebo 相机插件发布 `/camera/image_raw` 与相机信息。确认 `ros2 topic hz` 有帧率。
2. 在场景中放置 ArUco（Gazebo 模型或贴图）。字典与边长在参数中写死并记入笔记。
3. 编写检测节点：输出像素中心 \((u,v)\) 及可选位姿。图像窗口中绘制十字与检测框，便于判断误检。
4. 仿真手眼可先用 URDF 中的精确静态变换。用 `tf2` 查询 `base_link` → `camera_optical_frame`，核对手写连乘。
5. 将标签正前方、沿光轴后退一段距离的位姿作为 Commander 目标，只规划一次并执行。
6. 手动平移标签后重新运行，确认新目标变化。记录：运动过程中即使标签再动，臂仍走旧轨迹。

**检查。** 图像中可见标签；TF 树含相机光轴系；移动标签后目标更新，但单次执行中途不修正。

**常见问题。** 光学坐标系 Z 向前与 URDF 连杆轴不一致导致位姿翻转。先画坐标轴，再改控制。

**过关标准。** 能向他人说明“看见了但仍是开环”。保存一次成功 bag。

### 第 3 关 静态视觉速度闭环（核心关）

**目的。** 停止规划器，用误差连续修正速度，形成真正的视觉—控制闭环。

**原理。** 令像素误差 \(e=[u-u^{*},\,v-v^{*}]^{\mathrm{T}}\)，参考点 \((u^{*},v^{*})\) 取图像中心。比例律 \(v=-\lambda e\) 得到相机平面速度（再按深度与内参补齐三维速度，或先只做二维对中）。\(\dot{q}=J^{+}v\)，必要时用阻尼伪逆。速度必须限幅。当 \(\|e\|<\varepsilon\) 并保持若干周期，进入保持。

**操作步骤。**

1. 仍用第 1 关将末端送到标签大致前方，然后切换状态 `SERVO`，此后禁止调用 `plan()`。
2. 伺服节点订阅图像检测与 `/joint_states`，查询 TF，计算 \(e\)、\(v\)、\(\dot{q}\)。
3. 确认 `ros2_control` 中存在速度接口或可切换的速度控制器。若仅有位置接口，不得用低频位置点冒充闭环；应配置速度控制器或等效的伺服接口（如 MoveIt Servo 的底层速度命令，但必须自己计算误差，不得把 Servo 当黑盒交差）。
4. 发布关节速度或笛卡尔速度。同时发布 `e` 便于绘图。
5. 安全：检测失败超过设定帧数则速度清零；\(\|\dot{q}\|\) 超限则降速或中止；工作空间盒外中止。
6. 将标签初始偏置（例如图像中偏左右上各一组），每组伺服至收敛或超时。
7. 调参只改变 \(\lambda\) 与限幅。先小 \(\lambda\) 至能缓慢对中，再增大至出现振荡后回退。

**检查。** `ros2 topic echo` 观察误差单调或阻尼收敛；RViz 中末端连续微动而非一次长轨迹；日志中无 `plan()`。

**常见问题。** 反向运动：误差符号或相机轴。振荡：\(\lambda\) 过大或未限幅。不动：速度控制器未切换、雅可比关节顺序错误。

**过关标准。** 不重新规划即可将标签压向图像中心，且能书面指出至少一次失败的原因。本关是进组演示的最低完成线。

### 第 4 关 静态开环与闭环对照

**目的。** 用课题组用语“稳、准、快”把第 2 关与第 3 关变成实验，而不是演示视频。

**操作步骤。**

1. 固定标签、固定初始关节、固定相机参数。编写脚本切换 `MODE=open` 与 `MODE=closed`。
2. 开环：检测一次，Commander 执行到位后记录最终 \(\|e\|\) 与总时间。
3. 闭环：同一初始条件进入伺服，记录 \(\|e\|(t)\)、进入 \(\varepsilon\) 的时间、超调与振荡次数。
4. 每模式重复不少于 5 次。超时、看丢、碰撞记失败，不得删除失败样本。
5. 由 bag 用脚本出表与曲线，禁止只凭目视填写数字。

**过关标准。** 一张对照表加一段文字，说明闭环在何指标上更好，以及是否在“快”上牺牲了“稳”。

### 第 5 关 运动目标、图像延迟与三种控制律

**目的。** 在第 3 关稳定之后增加思考量：目标时变、反馈过时。

**原理。** 固定 \(\lambda\) 在延迟下相当于用过时误差持续加油门，易振荡。降增益牺牲快速性换稳定性。一拍预测 \(\hat{e}\approx e+\Delta t\cdot\dot{e}\) 可能减小滞后，但模型不准时会加大超调。三种律必须共享同一测量、同一限幅与同一停机逻辑，只替换控制块。

**操作步骤。**

1. 仿真中让标签沿直线或圆弧慢速运动；不可突然瞬移。
2. 在检测与控制之间加入环形缓冲，按参数 `image_delay_ms` 输出过时帧。
3. 实现三个可切换插件或参数：`law:=p`、`law:=gain_schedule`、`law:=predict`。
4. 按下列格子收集数据（每格重复多次）：静止无延迟、静止有延迟、慢速运动有延迟。
5. 记录跟踪误差均值、峰值、振荡与失败率。绘制同一初始条件下三条误差曲线。
6. 写失败分析：指出预测律在哪一档延迟上劣于降增益。

**过关标准。** 参数可在 launch 中复现；能用离散闭环语言解释表格，而不是只报告“调小了更好”。本关是练习含金量完成线，仍不是顶刊题目。

---

### 第 6 关 真机复现（须导师同意）

**目的。** 验证同一套节点在标定误差与真实延迟下仍然可运行。占机时间应短，调参回到仿真。

**操作步骤。**

1. 向导师确认臂型号、官方 ROS 2 驱动、相机安装方式与安全规程。不得在未限速时启用伺服。
2. 使能、急停、TCP 直线运动复检。用官方例程确认硬件接口正常。
3. 打印标签，固定眼在手相机，做手眼标定，记录重投影或标定残差（此即“准”的上限）。
4. 先复现第 3 关静态对准，限速为仿真的保守值。再视时间复现第 4 关。第 5 关可用手缓慢移动标签纸，延迟仍由软件注入。
5. 全程录 bag。实验结束复位、松使能、整理线缆。

**过关标准。** 真机表与仿真结论方向一致，或能解释不一致来自标定与延迟而非程序错误。

## 第五章 安全、开源与后续课题

伺服必须限速、限工作空间并在看丢时停机。真机实验须有人在急停旁。开源范围限于自编的 `vs_practice` 包、可公开仿真世界与本报告；实验室地址、内部驱动与商业网格不得上传。后续大三年级仅允许增加一个控制增量：延迟下的稳定律细化，或 6/7 轴浅零空间对照。不得将第 3 关单独作为投稿题目。
